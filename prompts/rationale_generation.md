# R3 v4 — Artifact + Raw + Law / Few-shot / 4단계 논증 계약

당신은 공식 방송통신심의 사례를 방송 전 사전검토용 합성데이터로 변환하는 데이터 편집자다.

제공된 Gold 규정은 이미 확정되어 있다. 새로운 규정을 검색하거나 추가하지 말고, 각 Gold 규정에 대해 최종 제작안의 구체적인 사실, 그 사실의 문제성, 해당 조문의 판단 요건, 방송 전 검토 결론이 순서대로 이어지는 rationale을 작성하라.

## 입력 자료의 역할과 우선순위

1. `artifact`: 최종 평가 모델이 보는 방송 전 제작안이며 rationale이 직접 설명해야 하는 사실 범위다.
2. `raw_text`: artifact의 사실을 공식 원문과 대조하고 공식 판단 취지를 이해하기 위한 provenance다. raw_text에만 있는 사후 사실을 평가 모델이 예측해야 하는 핵심 근거로 사용하지 않는다.
3. `gold_rules`: rationale이 참조해야 하는 법적 기준이다. 제공된 rule 이외의 규정을 추가하지 않는다.

## 규정별 4단계 논증 계약

각 Gold rule의 `rationale_sentences`는 아래 순서의 문자열을 정확히 4개 포함한다.

1. 문제 상황: artifact에서 확인되는 구체적인 장면·대사·자막·표현을 객관적으로 서술한다. 이 항목에서는 규정명이나 법적 판단을 언급하지 않는다.
2. 문제성 판단: 첫 번째 항목의 사실이 시청자 오인, 정보 부족, 과도한 표현, 권리 침해 등 어떤 문제를 일으키는지 설명하고, “문제가 있다” 또는 “문제가 있다고 보기 어렵다”는 판단을 명확히 제시한다. 이 항목에서는 규정을 인용하지 않는다.
3. 규정 근거 및 요건 연결: 입력으로 제공된 해당 rule의 `rule_text` 전체를 빠짐없이, 표현을 바꾸지 않고 직접 인용한 뒤, 첫 번째·두 번째 항목의 사실과 문제가 해당 규정의 어떤 요건에 해당하는지 또는 해당하지 않는지를 설명한다. 규정명과 조항도 함께 밝히며, 규정만 인용하고 끝내서는 안 된다.
4. 검토 결론: 위 판단을 종합하여 해당 표현이나 구성의 수정·삭제·보완이 필요한지 또는 현재 구성을 유지할 수 있는지를 방송 전 검토 관점에서 결론으로 제시한다.

배열 항목은 반드시 4개여야 한다. 세 번째 항목의 `rule_text` 내부에 여러 문장이나 줄바꿈이 있어도 하나의 배열 항목으로 유지한다.

## 작성 원칙

1. 첫 번째 항목은 artifact의 사실만 서술하고 artifact를 통째로 반복하지 않는다.
2. 두 번째 항목은 사실이 야기하는 실질적인 문제를 설명하며, 규정명·조항·법적 요건을 선취하지 않는다.
3. 세 번째 항목은 규정 원문 인용과 요건 적용을 모두 포함한다. 인용만 하거나 두 번째 항목을 그대로 반복하지 않는다.
4. 네 번째 항목은 수정·삭제·보완·유지 등 방송 전 조치를 명확하게 결론으로 제시하되, artifact와 Gold rule에서 직접 도출할 수 있는 최소한의 방향만 제시한다. 입력에 없는 새로운 제작 방식이나 조치의 세부 내용을 만들지 않는다.
5. artifact와 raw_text의 표현이 다르면 raw_text로 의미를 확인하되, 최종 rationale에서는 artifact에서 확인할 수 있는 사실을 기준으로 설명한다.
6. 입력에 없는 사실과 제공되지 않은 규정을 만들지 않는다.
7. 위원회 논의·의결 절차, 공식 처분, 민원, 사후 조치와 감경 사유를 포함하지 않는다.
8. 공식 처분을 재진술하지 않고 방송 전 검토 문체로 작성한다.
9. Gold rule이 주어졌다는 이유만으로 항상 위험하다고 판단하지 않는다. 요건이 충족되지 않으면 두 번째 항목에서 “문제가 있다고 보기 어렵다”고 판단하고, 세 번째와 네 번째 항목에서도 그 이유와 결론을 일관되게 설명한다.
10. 금지형 규정은 ‘금지되는 표현에 해당한다’, 의무형 규정은 ‘해당 의무를 충족하지 못한다’ 또는 ‘해당 의무에 어긋난다’고 서술한다. 위반을 설명하면서 ‘요건에 해당하지 않는다’고 표현하지 않는다.
11. 복수 rule은 rationale을 분리하고 `gold_rules`의 입력 순서를 유지하며, `overall_answer`에서만 종합한다.
12. Gold rule이 하나이면 `overall_answer`는 `null`, 둘 이상이면 종합 답변을 작성한다.
13. 출력은 지정된 JSON object만 사용하고 다른 설명을 추가하지 않는다.

## 예시 1 — 단일 rule·문제 있음

입력:

```json
{
  "artifact": "6월 12일 방송 예정인 대출상품 광고를 제작 중이다. ‘직업과 신용등급에 관계없이 누구나 즉시 승인’이라는 자막과 내레이션을 사용하며, 별도의 심사 조건 안내는 광고안에 포함되어 있지 않다.",
  "raw_text": "대출상품 광고에서 ‘직업과 신용등급에 관계없이 누구나 즉시 승인’이라고 표현하고 별도의 심사 조건을 안내하지 않았다. 실제로는 별도 심사가 적용되어 소비자를 오인하게 할 수 있다고 판단하였다.",
  "gold_rules": [
    {
      "rule_id": "DEMO_AD_ART1",
      "regulation": "방송광고심의에 관한 규정",
      "article": "제1조",
      "rule_text": "금융상품 광고는 별도의 심사 없이 누구나 승인되는 것처럼 사실과 다르게 표현해서는 아니 된다."
    }
  ]
}
```

출력:

```json
{
  "rationales": [
    {
      "rule_id": "DEMO_AD_ART1",
      "rationale_sentences": [
        "광고안은 직업과 신용등급에 관계없이 누구나 즉시 승인된다고 표현하면서 별도의 심사 조건은 안내하지 않는다.",
        "실제 심사가 적용되는 상품을 조건 없이 승인되는 것처럼 전달하여 소비자가 승인 가능성을 오인할 수 있다는 문제가 있다.",
        "「방송광고심의에 관한 규정」 제1조는 ‘금융상품 광고는 별도의 심사 없이 누구나 승인되는 것처럼 사실과 다르게 표현해서는 아니 된다.’라고 규정하므로, 심사 조건을 생략한 채 누구나 즉시 승인된다고 표현한 구성은 사실과 다른 무조건 승인 표현을 금지하는 요건에 해당한다.",
        "따라서 즉시 승인 문구를 수정하고 실제 심사 조건을 명확히 안내한 후 방송할 필요가 있다."
      ]
    }
  ],
  "overall_answer": null
}
```

## 예시 2 — 복수 rule·문제 있음

```json
{
  "artifact": "뉴스 프로그램에서 범죄 피해 아동의 실명과 학교를 원고와 자막에 포함하고, 피해 아동의 얼굴이 식별되는 영상을 별도의 모자이크 없이 사용할 예정이다.",
  "raw_text": "뉴스 프로그램에서 범죄 피해 아동의 실명과 학교를 언급하고 얼굴을 모자이크 없이 보여주었다. 피해 아동의 신원과 사생활이 노출될 수 있다고 판단하였다.",
  "gold_rules": [
    {
      "rule_id": "DEMO_BR_ART1",
      "regulation": "방송심의에 관한 규정",
      "article": "제1조",
      "rule_text": "방송은 피해 아동의 신원을 알 수 있는 정보를 공개해서는 아니 된다."
    },
    {
      "rule_id": "DEMO_BR_ART2",
      "regulation": "방송심의에 관한 규정",
      "article": "제2조",
      "rule_text": "방송은 개인의 얼굴 등 사생활을 부당하게 침해하지 않도록 해야 한다."
    }
  ]
}
```

```json
        "따라서 피해 아동의 얼굴 영상은 방송 전에 모자이크 등 비식별 처리를 할 필요가 있다."

```

## 예시 3 — 문제 있다고 보기 어려움

입력:

```json
{
  "artifact": "렌탈상품 광고에서 월 이용료와 함께 ‘36개월 의무사용, 중도해지 시 위약금 발생’이라는 조건을 동일한 화면에 표시할 예정이다.",
  "raw_text": "렌탈상품 광고에서 월 이용료와 함께 ‘36개월 의무사용, 중도해지 시 위약금 발생’이라는 자막을 동일한 화면에 표시하였다. 주요 계약조건이 함께 고지되어 문제가 없는 것으로 판단하였다.",
  "gold_rules": [
    {
      "rule_id": "DEMO_AD_ART2",
      "regulation": "방송광고심의에 관한 규정",
      "article": "제2조",
      "rule_text": "광고는 계약기간, 위약금 등 소비자의 구매 결정에 중요한 거래조건을 명확히 표시해야 한다."
    }
  ]
}
```

출력:

```json
{
  "rationales": [
    {
      "rule_id": "DEMO_AD_ART2",
      "rationale_sentences": [
        "광고안은 월 이용료와 함께 36개월 의무사용 기간 및 중도해지 위약금 조건을 같은 화면에 표시한다.",
        "소비자의 구매 결정에 중요한 계약기간과 위약금이 함께 제시되어 거래조건의 누락이나 오인 문제가 있다고 보기 어렵다.",
        "「방송광고심의에 관한 규정」 제2조는 ‘광고는 계약기간, 위약금 등 소비자의 구매 결정에 중요한 거래조건을 명확히 표시해야 한다.’라고 규정하며, 제작안은 계약기간과 위약금을 같은 화면에 명시하므로 중요한 거래조건의 표시 요건을 충족한다.",
        "따라서 제공된 제작안은 해당 거래조건 표시를 유지할 수 있으며, 이 요건을 근거로 추가 수정할 필요는 없다."
      ]
    }
  ],
  "overall_answer": null
}
```

## 이번 입력

```text
artifact:
{ARTIFACT}

raw_text:
{RAW_TEXT}

gold_rules:
{GOLD_RULES}
```

## 출력

앞의 JSON 형식만 출력한다.
